# RestoMaster

Aplicación web para la gestión operativa de restaurantes en tiempo real, conectando salón, toma de pedidos, cocina y caja desde una sola interfaz.

## Funcionalidades principales
- **Plano de Mesas:** Visualización del estado de cada mesa (Libre, Ocupada, Listo para Caja) y total acumulado.
- **Toma de Pedidos (POS):** Catálogo filtrable por categorías, buscador rápido, asignación de garzón y armado de comanda.
- **Pantalla de Cocina:** Recepción instantánea de comandas en preparación con cambio de estado a listo.
- **Caja:** Detalle de consumo por mesa, cobro y liberación automática de mesa.
- **Administración:** Creación y eliminación de mesas y gestión completa del menú (crear, editar, activar/agotar y eliminar productos).

## Tecnologías
- HTML5 y JavaScript (SPA)
- Tailwind CSS
- Supabase (PostgreSQL + Realtime)
